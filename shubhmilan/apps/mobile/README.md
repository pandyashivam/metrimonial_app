# @shubhmilan/mobile

Expo (SDK 51) Router app. Ships on iOS, Android, and web (via `react-native-web`).

```bash
pnpm dev           # starts Expo on :8081
pnpm ios           # run iOS simulator (macOS)
pnpm android       # run Android emulator
pnpm web           # start web build
```

Configure `EXPO_PUBLIC_API_URL` in `.env` (defaults to `http://localhost:4000/api/v1`).
